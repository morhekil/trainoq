title: Show full values in two-value set steppers at 320px
created_at: 2026-10-08T17:25:00+11:00
---

At 320px, two-value set rows (weight × reps) cut off two-digit values: the `logged-day-320` and `bench-angle-row-320` screenshots show "40" as "4(" and "15" as "1!". The baseline from before the effort work shows the same thing, so the effort change did not cause it. Three-value rows switch to compact number fields and show their values in full.

Make every stepper value readable at 320px and at 200% zoom, for example by narrowing the ± buttons or switching to compact fields below a container width. Update the affected screenshots on purpose.
